# Superstore Sales Analysis & Business Intelligence Dashboard

An end-to-end data analytics project focused on analyzing retail sales performance, profitability, customer behavior, and business trends using Python and interactive visualizations.

## Project Overview

This project transforms raw Superstore sales data into meaningful business insights. It includes data cleaning, exploratory data analysis, business performance evaluation, and an interactive Streamlit dashboard.

## Objectives

- Analyze overall sales and profit performance.
- Identify monthly sales trends.
- Compare category and regional performance.
- Understand customer purchasing behavior.
- Evaluate the relationship between discounts and profitability.
- Present insights through an interactive dashboard.

## Tools & Technologies

- Python
- Pandas
- Plotly
- Streamlit
- Jupyter Notebook
- GitHub

## Dataset

- Original dataset: Superstore Sales
- Cleaned records: 9,994
- Key information: Orders, sales, profit, products, customers, regions, and discounts.

## Key Business Insights

| Metric | Result |
|---|---:|
| Total Sales | $2,297,200.86 |
| Total Profit | $286,397.02 |
| Total Orders | 5,009 |
| Total Customers | 793 |
| Average Discount | 16% |
| Profit Margin | 12.47% |

### Category Performance

- Technology generated the highest sales and profit.
- Furniture generated comparatively lower profit.
- Office Supplies contributed significantly to overall profitability.

## How to Run the Dashboard

1. Clone or download this repository.
2. Install the required libraries:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
streamlit run app.py
```
